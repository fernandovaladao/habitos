# Protótipos

Estas imagens foram **regeneradas** após a perda dos arquivos originais causada pela reinstalação do computador.

Elas preservam as decisões funcionais e a identidade visual aprovada (azul, laranja e branco), mas não são reproduções pixel a pixel dos protótipos anteriores.

A ERS é a fonte de verdade para comportamento e regras. O arquivo oficial do logotipo Chromos deverá substituir a marca visual reconstruída quando estiver disponível.
